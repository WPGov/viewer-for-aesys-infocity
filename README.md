Visualizza i display AESYS in post, pagine e widget: un nuovo strumento di informazione utile, facile e veloce!

## Funzionalità

- Blocco per l'editor e shortcode `[aesys id="696" title="Informazioni Municipali"]` per post, pagine e widget
- Titolo, larghezza e altezza personalizzabili per ogni display
- Cache locale delle immagini, aggiornata ogni 15 minuti
- Pagina di amministrazione con l'anteprima di tutti i display configurati
- Pensato per Comuni ed enti pubblici, nell'ambito del progetto [WPGov.it](https://www.wpgov.it)

Plugin non ufficiale rilasciato previo accordo con AESYS S.p.A. Il marchio "MyInfoCity" e la tecnologia cloud dei display "Informacittà" sono di proprietà di AESYS S.p.A.

## Installazione

Installalo dall'amministrazione di WordPress (**Plugin → Aggiungi nuovo**, cerca "Aesys MyInfo.City Viewer") oppure scaricalo da [WordPress.org](https://wordpress.org/plugins/viewer-for-aesys-infocity/).
